# EdgeOS 3 中文助手

在浏览器中为 EdgeOS 管理界面添加中文。已在 **EdgeRouter X / EdgeOS 3.0.1** 上验证；其他型号和固件版本尚未验证。

配置树采用“中文名称（英文参数）”，例如“远程访问（remote-access）”。输入值、选项值、自定义名称、配置路径与 CLI 命令保留原样。切换英文时恢复原始显示。

## 安装与更新

1. 安装 [Tampermonkey 官方扩展](https://www.tampermonkey.net/)。
2. 点击 [安装最新版脚本](https://raw.githubusercontent.com/hl9565/edgeos-zh-cn/main/dist/edgeos-zh-cn.user.js)，在 Tampermonkey 的安装界面确认安装。
3. 刷新已登录的路由器页面。右下角的“中文 · 切换 English”表示脚本已运行。

默认仅支持 `http://192.168.1.1/` 和 `https://192.168.1.1/`。如果路由器使用其他地址，需同时修改脚本头部两行 `@match` 和脚本开头的 `location.hostname` 检查。不要扩大到所有网站。

已经安装旧版的用户，可在原脚本编辑器中替换为新版内容、保存并刷新，不需要新建第二个脚本。项目保留原有脚本名称与 namespace。**v1.6.1 增加 GitHub 下载与更新地址**，安装后可由 Tampermonkey 检查后续更新；此前手动安装的版本需要先更新一次。也可从 [Releases](https://github.com/hl9565/edgeos-zh-cn/releases) 下载固定版本。

如果不生效，请确认脚本已启用，并按 Chrome/Tampermonkey 的提示启用“允许用户脚本”。这属于浏览器扩展设置，不需要更改路由器配置。

## 已覆盖内容

- 1280 个常规界面词条，包括导航、按钮、表格、提示和常见动态消息。
- 1284 个配置树名称、2189 条帮助说明，包括 VPN、BGP、OSPF、MPLS、DHCPv6、OpenVPN、SNMP 和流量控制。
- 对照 EdgeOS 3.0.1 的 6631 项原厂配置定义，所有参数名称及非空帮助都有对应翻译。数量包含重复结构及兼容词条，完整覆盖结论限于该版本的配置树模板。

协议缩写、英文参数标识、命令示例、文件路径及文档链接会保留。没有明确 `value` 的选项也保留原文，以免改变实际提交值。此项目不承诺所有固件或所有页面百分之百汉化。

## 运行方式

脚本只修改当前浏览器的显示，不替换路由器文件，不调用配置 API，不自动保存或应用配置。首次处理页面，后续处理变化的部分。独立 CLI 页面不运行汉化，英文模式停止页面观察器。

脚本自身不主动联网、不上传配置。Tampermonkey 的安装和更新功能会从本 GitHub 仓库下载脚本。停用脚本并刷新即可恢复原厂界面。

## 开发与验证

需要 Python 3.9+ 和 Node.js 18+：

```sh
npm ci
npm run build
npm test
```

`src/engine.js` 是显示层逻辑，`locales/` 保存翻译，`scripts/build.py` 生成 `dist/` 中可安装的独立脚本。发布版本由 `package.json` 的 `version` 决定。

本仓库使用自行编写的 DOM 测试样例，验证表单值与英文路径保护、节点与事件保留、动态更新、自定义名称、中英文恢复、翻译语料及无脚本网络请求。最初在本地使用原厂模板完成的 76 项验证和真实页面抽查也已通过；原厂 JS、CSS、模板归档、设备配置及检查记录不随仓库分发。
